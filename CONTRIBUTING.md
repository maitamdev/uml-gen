# Contributing to UML Generator

## Development Setup
1. Clone the repo: git clone https://github.com/maitamdev/uml-gen.git
2. Install dependencies: npm install
3. Start dev server: npm run dev

## Project Structure
- src/main.ts - Main application entry
- src/ai-generator.ts - AI provider integration
- src/diagram-renderer.ts - Mermaid rendering engine
- src/diagram-interactive.ts - Drag and drop nodes
- src/export.ts - SVG/PNG export
- src/templates.ts - Pre-built diagram templates
- src/utils/ - Utility functions
- src/types.ts - TypeScript type definitions
- src/constants.ts - Application constants

## Code Style
- TypeScript strict mode
- Functional programming preferred
- Vietnamese for user-facing text
- English for code identifiers

## Commit Convention
- feat: New feature
- fix: Bug fix
- chore: Maintenance
- docs: Documentation
- style: Formatting
- refactor: Code restructuring
